EDUNUSA INTERNATIONAL SCHOOL - WEBSITE AKADEMIK

Isi folder:
- index.html: halaman utama
- detail.html: halaman detail kegiatan (konten mengikuti parameter id)
- style.css: tampilan dan responsive layout
- script.js: navigasi mobile dan konten detail kegiatan
- img/: logo dan foto-foto website

CARA UPDATE GITHUB PAGES:
1. Extract ZIP ini.
2. Upload/replace seluruh isi folder proyek ke repository GitHub (pastikan index.html ada di root repository).
3. Pastikan folder img ikut ter-upload.
4. Commit changes ke branch main.
5. Buka GitHub Pages dan refresh website.

Catatan: EduNusa adalah konsep sekolah untuk tugas. Data kontak, statistik, tanggal, dan informasi sekolah merupakan contoh dan dapat disesuaikan.
